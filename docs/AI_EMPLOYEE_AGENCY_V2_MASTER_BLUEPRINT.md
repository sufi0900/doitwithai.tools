## 1. Executive Summary & Unit Economics (90% Deterministic Code + 10% LLM Intelligence)

- **90% Zero-Cost Deterministic Execution ($0.00)**: Live HTML crawling (`<title>`, `<meta>`, `H1–H3`, `robots.txt`, `llms.txt`), Google Autocomplete scraping, On-Page SEO Idea Donut & Competitor Gap diffing, 0.00 CLS SVG rendering, 60fps Node Graph animations, and CMS REST API publishing all run on deterministic TypeScript code without spending a single API token.
- **10% High-Intelligence LLM API Layer ($0.0192 per Full Agency Circle)**: External LLM API calls ([Gemini 2.5 Flash](https://creditforstartups.com/pricing/gemini-api-pricing), [OpenAI GPT-4o-mini](https://www.aipricing.guru/models/gpt-4o-mini/), or [Groq Llama 3.3 70B](https://www.spheron.network/blog/groq-api-pricing-2026-cost-per-token-vs-gpu-rental/)) are reserved strictly for high-value cognitive tasks.
