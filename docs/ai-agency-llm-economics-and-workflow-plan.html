Visual Audit of Our Live Vercel Dashboard (What Phase 6 Fixes Immediately)

Inspecting our live deployment at /ai-employee-agency/dashboard revealed four specific UI/UX defects that make the interface feel crowded and robotic:

  1. Node Graph Top Bar Collision: The top-left toolbar (12 Core Desks, All 9 Departments, + Zoom In, - Zoom Out) collides with the top-right status pill, hiding the Zoom buttons underneath.
  2. Missing Full-Screen Canvas Mode: Users need a dedicated Expand Full Screen button inside the graph so the interactive node canvas fills 100% of the monitor (100vw × 100vh) with floating bottom-right Zoom/Pan/Fit controls.
  3. Emoji Clutter & Truncated Sidebar Labels: The left sidebar uses cartoon emojis and truncates labels (Content Writing S..., Graphic & Visual ...). Replacing emojis with crisp 16px SVG icons and widening the sidebar gives clean, single-line scannability.
  4. Bottom-Right Floating Widget Overlap: The global purple AI chat button covers the right edge of the Send Command button in the bottom dock (fixed by adding right clearance and a compact dock layout).

How Real-Time Token Tracking Works on a $0 Free API Key (Phase 7)

Even when we test with a free API key from Google AI Studio or Groq Cloud, the API response is never blind: every JSON payload includes exact token counters (usageMetadata.promptTokenCount, candidatesTokenCount, and thoughtsTokenCount).

In Phase 7, our token-telemetry-store.ts records the exact tokens used by each department during 1 Full Agency Circle and multiplies them by official paid rates ($0.30/1M input & $2.50/1M output on Gemini 2.5 Flash) so you see the exact token count, per-circle cost ($0.0192), and 30-day projected monthly cost ($0.58–$1.20/mo) live on the dashboard while paying $0 during testing.
