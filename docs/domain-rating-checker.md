# Domain Rating checker withdrawn

Status: dropped by Sufian on October 27, 2026, after receiving an Ahrefs support reply declining the planned public integration.

The supplied support screenshot states that displaying Ahrefs metrics inside a third-party public tool is not permitted under the policy described in that reply. This record concerns our proposed implementation, rather than a legal conclusion about every possible integration.

The checker page, API handler, provider integration, client, and dedicated tests have been removed. It was never added to the live catalog or public sitemap. Do not restore or schedule this tool without a new user decision and suitable data permissions.

The scheduled fourteen-item off-page and content-conversion queue is unchanged. This checker was a separate, immediate preview task.

Historical GitHub commits and immutable Vercel deployments may retain the removed implementation. Revoke the dedicated Ahrefs key in the Ahrefs account to stop historical deployments from making authorized provider requests. Removing current source alone does not revoke a provider credential.

No new authority score should be invented or presented as Ahrefs DR, Moz DA, or Semrush Authority Score.
